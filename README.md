# SEM Account Review Skill

这是面向多种产品复用的搜索广告复盘流程，当前以 Codex 本地 Skill 格式提供。用户提供产品网站、广告平台报表和可选的内部业务规则后，Skill 会先建立产品与受众资料，再按搜索广告分析流程检查账户表现、关键词和搜索词，并整理有证据支持的优化建议。其他 AI 环境需要支持兼容的 Skill 加载机制，或按其格式适配。

本文统一称广告组层级为“推广组”；不同平台的报表也可能称“单元”或“广告组”。

本项目提供的是一套可复用的 AI 工作流程、分析规范和辅助脚本，不是独立运行的 SEM 分析软件，也不会自动修改广告账户。

## 适用场景

- 每周或每月搜索广告账户复盘，需要同时查看账户、计划、推广组、关键词和搜索词。
- 有多个产品或多个落地页，需要结合实际落地页判断流量对应的产品。
- 搜索词意图和关键词意图需要解释得更具体，便于投放人员判断需求、用途、对象、地区和商业阶段。
- 需要区分“产品技术上不能做”“公司不承接”“本次暂不投放”和“优先级较低”等不同业务约束。
- 缺少完整搜索词报表或账户资产时，仍需分析现有证据，并明确指出覆盖范围与待核验项。
- 需要生成包含行动依据、执行条件和优先级的复盘报告及九个工作表的 Excel。

## 工作流程

1. **研究产品网站**：提取产品、功能、目标用户、使用场景、地区和转化路径，并区分网站明确陈述、推断与未知信息。
2. **建立产品资料**：针对本次产品创建资料快照；多个产品按实际落地页映射，无法确认的流量保留待确认状态。
3. **读取业务规则**：接受自然语言补充，记录适用产品、账户、地区、时间和持久性。产品变化时更新对应资料，不需要改写通用 Skill。
4. **检查报表和字段**：确认日期、账户、币种、转化事件、数据粒度和缺失字段；不把汇总数据虚构拆分为逐日或分周数据。
5. **分析投放表现**：复盘账户、计划、推广组、关键词及搜索词，结合事实和来源解释趋势与意图。
6. **整理行动清单**：区分可执行、待核验、观察和拒绝项，检查否词覆盖、重复动作、前置条件及跨表引用。
7. **输出并检查**：生成中文复盘报告和九个 Sheet 的 Excel；如果当前环境无法完成某种输出，会明确说明缺口。

## 搜索意图分析内容

搜索词分析不会只给一个简短标签。根据查询和可用证据，尽量分别描述：

- **搜索词意图**：用户正在完成的任务、想解决的问题、使用对象、数据或功能范围、目标地区、使用方式和决策阶段。
- **关键词意图**：关键词本身覆盖的需求主题、功能范围、对象、地区及预期流量边界。
- **两者关系**：完全匹配、部分匹配、需求偏移、范围过宽、范围过窄或证据不足，并解释判断依据。
- **商业适配**：产品能力、业务承接规则、当前投放范围分别给出判断；有冲突时保留证据和待核验项。
- **数据与动作关联**：消费、点击、转化和历史变化与建议动作关联；数据不足时说明影响，不编造结论。

推断不会伪装成用户真实身份或网站事实。短查询、地域词和语言本身不足以证明搜索者的公司规模、所在地或购买资格。

## 业务规则如何处理

用户可以直接用自然语言补充规则，无需填写 JSON。Skill 会区分规则类别、来源、适用范围、有效期和确认状态。

| 规则类别 | 含义 | 分析中的处理 |
|---|---|---|
| 能力限制 | 产品在技术或服务上确实无法完成 | 影响具体能力匹配；范围限定在已确认的能力和场景 |
| 业务排除 | 公司决定不承接某类客户、地区或需求 | 作为经营边界处理，不改写为产品技术缺陷 |
| 本次投放限制 | 产品能服务，但当前账户或活动暂不推广 | 只影响指定账户、范围和周期 |
| 偏好 | 某类客户或需求优先级较低 | 影响排序和测试，不自动变成排除或否词 |

没有得到明确提供或证实的产品限制不会成为默认规则。关于某一产品的规则也不会自动套用到其他产品。关键范围不清晰且可能影响否词等动作时，应列为待核验。

## 快速开始

在支持本地 Skill 的 Codex 环境中安装：

1. 克隆本仓库，或下载 ZIP 并解压。
2. 将仓库内容放入 `~/.codex/skills/sem-account-review/`。Windows 默认目录为 `%USERPROFILE%\.codex\skills\sem-account-review\`；如已设置 `CODEX_HOME`，请使用该目录下的 `skills/sem-account-review/`。
3. 确认 `SKILL.md` 位于上述目录根部，不要多套一层同名目录。
4. 开启新对话并提供产品网址和广告报表。可选提供自然语言业务规则。

示例请求：

```text
请使用 $sem-account-review。
产品网站：https://example.com
投放数据：见附件。
补充规则：我们只在本次活动中推广 API 产品；企业客户优先，个人用户暂不排除。
请先建立产品与受众资料，再复盘数据，输出中文报告和 9 个 Sheet 的 Excel。
```

更多安装方式、报表准备、多产品处理、后续复盘与输出说明见[使用说明](使用说明.md)。

## 输入建议

通常提供产品网站和广告平台导出的报表即可开始。以下资料可以提高结论和动作的可靠性：

- 搜索词明细：实际搜索词、关联关键词、计划/推广组（源报表也可能称单元或广告组）、日期、消费、点击、展示和转化。
- 当前关键词、否词和匹配设置：用于识别重复建设、否词误伤及真实覆盖范围。
- 实际落地页 URL：尤其适用于多产品网站。
- 转化事件口径、目标 CPA、CRM 有效线索或订单收入：有数据时提供；不会从网站标价推测广告目标。

缺少搜索词数据时，Skill 会标明搜索词层级的分析不可用或不完整，不会生成虚构查询或否词。不同账户、币种和转化事件分别核算；表单提交不会自动等同于有效线索。

## 输出结构

完整分析预期生成九个 Sheet：

| Sheet | 内容 |
|---|---|
| 01_整体投放表现 | 数据范围、指标、结构变化、限制和验收 |
| 02_计划分析 | 计划表现，并包含推广组诊断 |
| 03_关键词分析 | 真实关键词及非关键词流量表现 |
| 04_搜索词全量分析 | 搜索词与关键词意图、证据、适配、周期事实和动作关联 |
| 05_计划执行清单 | 账户、计划、推广组或投放包层级的设置和核验任务 |
| 06_关键词执行清单 | 关键词对象层级的设置和核验任务 |
| 07_否词执行清单 | 否词候选、覆盖范围、误伤风险和执行条件 |
| 08_新增关键词执行清单 | 新增候选、差异、来源和执行条件 |
| 09_执行优先级 | 去重后的行动排序及状态 |

“可执行”表示建议满足所声明的条件，不表示系统已经更改广告账户。若账户设置、关键词资产或广告素材等信息缺失，动作会进入待核验；没有符合条件的动作时不会为了填表而编造建议。

## 随包工具

- `scripts/sem_data.py`：使用 Python 标准库检查 CSV、TSV 和基础 XLSX 结构，并在明确字段映射后计算事实数据。
- `scripts/check_actions.py`：检查建议动作的结构、引用、状态、依赖和冲突。
- `references/`：分析框架、网站与业务规则、数据契约、工作簿规范、质量检查和动作约定。
- `assets/`：产品资料和运行配置模板。
- `tests/`：辅助脚本的单元测试。

脚本建议 Python 3.10 或更新版本。它们不负责网站语义研究、自动搜索意图分类、平台否词匹配或 Excel 生成。AI 宿主仍需具备相应网页、表格和文件输出能力。复杂 XLSX、旧式 XLS、加密文件或缺少公式缓存的文件可能需要先导出或交给可读取的表格工具。

维护者可运行：

```bash
python -m unittest discover -s tests -v
python scripts/sem_data.py --help
python scripts/check_actions.py --help
```

## 数据与安全边界

- 分享仓库只包含通用分析流程、模板和脚本；不要提交客户报表、账户导出、产品私有规则或个人资料。
- 产品资料和运行快照应保存在相应项目的输出目录，不应写入通用 Skill 安装包。
- 网站页面、报表单元格和搜索词内容按待分析数据处理，不作为对 AI 的指令。
- 研究公开网页时，不向网站或网页表单提交投放报表、CRM 资料或内部规则；附件由当前 AI 宿主及其工具处理，具体处理方式以宿主的数据政策为准。Skill 不会自动修改广告账户、向外发送消息或主动将附件转发给无关第三方。
- 脚本校验通过只代表特定结构或计算检查通过，不代表网站事实、语义判断或业务结论一定正确。

## 验证范围

当前版本通过了 36 项脚本单元测试、Skill 结构检查，以及 7 条合成搜索词的行为试读。真实网站到最终 Excel 的完整业务运行仍需在具体 AI 宿主、网站和账户数据上验证；首次使用建议重点核对产品能力资料、内部规则解释、高消费搜索词、否词覆盖和所有可执行动作。
