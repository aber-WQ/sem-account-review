# 固定九表交付规范

分析定义见 [analysis-framework.md](analysis-framework.md)，输入和转化粒度见 [data-contract.md](data-contract.md)，校验见 [quality-checks.md](quality-checks.md)。网站与人工规则资料按 [website-and-rules.md](website-and-rules.md) 独立保存，避免把一家产品限制写成通用规则。

## 通用约束

生成实际可打开的 `.xlsx`；不以 Markdown 表格冒充。固定以下 9 个 Sheet，不增加第 10 个。可在 02 内另设推广组表；来源、产品资料、动作详细集合、校验结果可另附可追溯文件。未生成时明确说明，不能声称交付完成。

默认一份工作簿一个账户、一个币种。多账户/币种增加作用域列，01独立分区，所有键包含账户；没有换算依据不合并货币指标。同名对象和历史归属变化增加平台 ID/版本定位列，不能仅依赖名称。

“本期”指最新分析期，W1为对比期；单期不造 W1。完整连续14天且用户未指定时可按前7天/后7天拆分，否则按真实覆盖说明。真实无量才写0，覆盖缺失保留缺失。03按真实对象聚合，02按事实发生时归属聚合；不可把跨组对象总量整行归到当前组。

**目标转化按已明确事件显示。** 单事件可将表头写为“目标转化（事件名）”；多个事件分别列相应事件计数/CVR/CPA，不相加为一个目标，不复制费用、展示和点击。目标不明保留原字段并注明不可直接解释。收入/ROAS等只有满足 analysis-framework 的事件、金额与归因条件时增列。未提供目标转化的数据，相关列保留未知/不可计算，不能填0。

**缺少搜索词明细**时，04/07/08保留表头并注明“缺少搜索词明细，无法完成对应分析”；03可用关键词报告做其支持的事实分析，搜索词质量、零转化关系消费等标不可计算。仅计划报告时，完成01/02并对其他表说明缺失。无可执行或待核验候选的动作表空表说明；不能据汇总数字生成虚假查询或凑动作。

字段按名称定位，不硬编码列字母。清晰表头、数值单元格、ID文本、过滤、冻结、可读性是交付要求；非适用字段可注明，不为填满每格编造内容。

## 01_整体投放表现

按顺序包含：

1. 平台、账户、币种、周期/天数、导出和归因口径、来源覆盖、产品资料版本、规则版本/有效期、目标事件和数据完整性。
2. 本期/W1基础：消费、展示、点击、CTR、CPC、各目标转化、CVR、CPA，具备条件时对应收入与ROAS。
3. 语义质量：零目标转化关系消费/占比、D1～D5消费、AI明确问题消费/占比、承接错配消费/占比、本次投放范围外消费/占比、能力匹配和综合意图合格消费/目标转化。
4. 否词可执行覆盖与待核验候选覆盖分列；若有多个否词取关系并集；标明资料覆盖范围，不称预计节省。
5. 环比、百分点变化，主要正/负因素、最大问题、最大机会及对应对象/动作ID。
6. 缺失/待核验事项及检查摘要：检查ID、实测结果、状态、失败位置。来源差额与语义覆盖不足清楚列出。

缺计算依据的指标显示原因；质量指标不强行以计划级总消费为分母。存在完整账户报告与可见搜索词两种覆盖时，分别列示并给披露覆盖比例，不要求假对平。

## 02_计划分析

主表每行一个报告可见计划，至少：

- 定位：计划ID/名称，必要账户、币种。
- 本期事实：消费及占比、展示、点击及占比、CTR、CPC、目标转化及贡献、CVR、CPA、零目标转化关系消费（可计算时）。
- 质量：明确问题消费/占比、承接错配消费、商业证据偏弱消费、待确认消费、本次范围外消费、综合意图合格消费/目标转化。
- 解释：计划角色/依据、规模与效率、主要问题、来源组/关键词、处理摘要、动作ID、适用规则ID。
- 双期：W1消费/点击/转化/CPC/CVR/CPA，W1零转化关系、明确问题、综合合格消费/转化，主要变化。

主表下方独立“推广组诊断”表，覆盖全部可见组：计划、组ID/名称、本期消费/点击/转化/CPA、明确问题/待确认/本次范围外消费、关键词或关系ID、处理摘要/动作ID；双期加W1消费/转化/CPA及趋势。此表不是重复计划汇总，程序不能把两区混加。

组级以上设置动作需引用整个作用域数据与覆盖说明，不能只列异常词。

## 03_关键词分析

一行一个数据契约中的真实承接对象，至少：

- 定位：计划、组、对象类型、关键词ID、关键词、当前实际匹配方式及证据。非关键词流量明确标对象类型，关键词ID为不适用，不计关键词个数。
- 本期事实：消费、展示、点击、CTR、CPC、目标转化、CVR、CPA、本期不同查询数、零目标转化关系消费。
- 质量：明确问题/占比、承接错配、待确认、本次范围外、综合意图合格消费/转化、Top1/Top3目标转化来源占比。
- 解释：目标意图/依据、质量结构摘要、典型匹配/错配查询及关系ID、核心问题、处理摘要、动作ID。
- 双期：W1消费/点击/转化/CPA、不同查询数、明确问题、综合意图合格消费/转化及趋势；双周并集数单独命名。
- 有来源证据时：本期/W1自动定向消费、各目标转化及引用；否则标不可计算，不能以语义猜触发方式。

包括保留、观察及无调整对象。报告可见关键词不等于完整账户资产；明确查重和当前设置来源限制。跨归属真实对象汇总要给历史版本信息。

## 04_搜索词全量分析

一行一个真实查询与承接对象、历史归属/必要职责版本的关系；关系和转化事实粒度依数据契约，多事件作为列或明示分区，不能复制消费后再相加。

基本前列：

`计划｜推广组｜关键词ID｜触发关键词/承接对象｜当前实际匹配方式｜搜索词｜本期展示｜本期消费｜本期点击｜本期目标转化（事件名）｜搜索词实际意图｜关键词目标意图`

多事件时在目标转化位置增列并明确事件；语义列相对位置可顺延，不得依赖固定列字母。当前匹配与当时触发关系分离，设置未知写未提供。

其后必需：

`匹配关系｜业务承接状态｜产品能力匹配度｜能力证据等级/来源｜商业意图｜本次投放范围状态｜适用规则ID/偏好影响｜词面证据｜语义置信度｜待确认项｜诊断分类｜本期最终处置｜本期新增状态｜本期否定状态｜原因判断｜当前动作摘要｜关联动作ID｜关系ID｜目标依据｜原始来源引用`

- 最终处置：保留 / 观察 / 拟排除 / 待核验 / 本期无独立动作。受范围动作影响写摘要及关联ID。
- 新增状态：可执行候选 / 待核验候选 / 不新增，引用08对应状态。
- 否定状态：可执行否定 / 待核验否定 / 不否定，引用07对应状态，且可执行时处于实际覆盖集合。

不在04另维护否定词、方式、层级和推荐词的第二套真值；由07/08通过动作ID引用，摘要从最终台账派生。

双期追加：`W1展示｜W1消费｜W1点击｜W1各目标转化｜双周事实趋势｜当前处置依据周期`。静态语义在同一规则/上下文版本中复用；确有能力、经营边界、职责变更则保留各期诊断版本与生效依据，不能一套当前规则无说明覆盖历史。

有明确细分来源时追加：`触发来源摘要｜本期自动定向消费/各目标转化｜W1自动定向消费/各目标转化`及来源证据。关系归属可靠性有限、相近关键词非实际触发时，增加归属含义/可靠性列，不虚构确定归属。

冻结表头及全部到“搜索词”的定位列；长文本可展开。两周无量/仅上期关系不删除，历史动作不自动继承。本期重要关系优先显示，W1及追溯列可分组折叠但不能省略。

## 05_计划执行清单

保留表名，承载账户/计划/组/投放包层级动作：

`动作ID｜优先级｜记录类型｜执行状态｜实际作用层级｜计划/组/投放包及ID｜当前值/状态｜目标值/明确核验事项｜作用域核心数据｜主要证据/问题｜适用规则/有效期｜前置条件及依赖｜调整目的｜观察/回退条件`

记录类型为变更建议/核验任务/观察。没有关键当前设置或目标值的变更建议待核验；核验任务具体说明查什么。组级自动定向仅在本表作主记录，06可引用，不能伪造关键词级关闭动作。

## 06_关键词执行清单

`动作ID｜优先级｜记录类型｜执行状态｜计划｜推广组｜关键词ID｜关键词｜当前实际匹配/状态｜目标匹配/状态或核验事项｜本期核心数据｜问题与证据｜配套动作ID｜前置条件｜观察/回退条件`

按真实对象及原子动作去重；不同匹配版本不能只按文本合并。普通无变更对象留03，重要观察或核验才进入本表。

## 07_否词执行清单

`动作ID｜优先级｜执行状态｜计划｜推广组/实际对象｜否定词｜否定方式｜否定层级｜排除性质/规则ID/有效期｜来源搜索文本数｜来源关系数｜覆盖关系数｜本期覆盖消费｜本期覆盖点击｜本期覆盖各目标转化｜来源/覆盖证据引用｜误伤风险｜具体原因｜明确动作｜前置条件/冲突处理`

来源数量和覆盖数量是不同数值列；完整关系集合过长则外附CSV/JSON等并链接。业务排除、能力错配、本次投放限制、局部路由明确区分。风险为低/中/高/待确认并说明。

匹配规则未知时只报告已确认下界或候选模拟范围，标待核验，不声称完整覆盖。可执行与待核验分别展示/筛选；汇总标明状态且覆盖取并集，不将来源行合计冒充实际作用域。

## 08_新增关键词执行清单

`动作ID｜优先级｜执行状态｜推荐计划｜推荐推广组｜来源搜索词/关系ID｜推荐关键词｜匹配方式｜新增依据｜处理方式｜来源周期与数据｜商业意图｜推荐原因｜标准化差异及风险｜适用规则/范围核验｜前置条件/查重范围｜观察条件`

来源周期分开，原查询事件不当成标准化词已验证。重要待核验机会可列，普通不采用词留04，不凑候选。明确业务排除不得成为新增机会。缺关键能力或范围资料时标待核验。

## 09_执行优先级

`总排序｜动作ID｜优先级｜记录类型｜执行状态｜执行对象及实际层级｜明确动作/核验任务｜关键证据｜前置条件/依赖｜观察目标｜来源Sheet`

仅从05～08引用最多30个本期重要去重动作，无最低数量和P1配额。依赖、状态、优先级与来源一致；P1核验任务不伪装成立即变更。摘要工作包不能与子动作重复计算收益。没有任务则空表说明。

## 格式与文件核验

- 使用 Excel 表或独立正确范围的筛选；02两区分别设置。冻结表头和关键对象列，04冻结到搜索词。
- 数值存数值，ID存文本，金额/百分比/日期格式一致；不将未知、缺失或零分母转成0。
- 文本换行、适当行高与列宽，意图/原因保留关键差异。不能固定行高遮住内容、无限AutoFit或删证据换美观。
- 参考列宽：数值10～14、定位18～26、意图/原因28～40，按内容调整；默认缩放可90%，必须实际检查属性。
- 不大量合并数据单元格。历史列/技术列可分组折叠，展开可读。
- 检查文件存在、可读、9表/字段/筛选/冻结/数值有效。关键范围渲染或Excel视觉检查；未具备条件明确未视觉验证，不把结构检查说成视觉通过。
- 文件名建议 `SEM搜索广告账户复盘_产品名_起始日期-结束日期.xlsx`，使用真实数据日期，不硬编码示例。
