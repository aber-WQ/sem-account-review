# 质量验收与回归案例

配合 [analysis-framework.md](analysis-framework.md)、[data-contract.md](data-contract.md)、[website-and-rules.md](website-and-rules.md)、[workbook-spec.md](workbook-spec.md) 使用。每项报告“通过 / 失败 / 待核验 / 不适用”，写实测结果、依据和失败位置；没有执行的检查不能标通过。

程序验证数值、键、集合、引用、状态和文件结构；语义判断用逐条解释、反例及重点复核。模型写“已检查”不等于程序验证，脚本通过不等于产品理解正确。

若已按 [action-contract.md](action-contract.md) 生成机器可读台账，运行对应动作检查脚本核验覆盖集合、动作链接和状态冲突；脚本不能验证网站事实、真实产品能力或平台匹配语义，这些仍需要来源证据与反例复核。

## 1. 检查清单

| ID | 检查 | 通过条件 |
|---|---|---|
| QA-01 | 来源与覆盖 | 文件/Sheet/行数/日期/粒度/排除/异常可追溯；全部可处理事实保留；未处理清单完整 |
| QA-02 | 周期与缺失 | 起止、日数、导出/归因时点明确；两周独立聚合；未导出/事件缺失不填0 |
| QA-03 | 对象与历史 | 平台ID与内部ID区分；降级键限制可见；同名不同匹配不误合并；移组/职责版本不被覆盖；无关键词流量不伪造关键词ID；多账户不冲突 |
| QA-04 | 数值对账 | 同覆盖04→03总量一致，04按历史归属→组→计划→01一致；不同报告覆盖差额单列；汇总行、事件行和跨组对象无重复消费；比率重新算 |
| QA-05 | 转化与分母 | 目标事件及去重/归因明确；混合事件不相加；0转化CPA不为0；空白非0；CVR异常需核验不截断；公式、数值、缓存及摘要一致 |
| QA-06 | 产品资料证据 | 来源链接/日期、官网声明/用户确认/推断/未知分开；未公开不等于不支持；营销宣传不冒充实测；多产品落地页对应及未知可追溯 |
| QA-07 | 人工规则分层 | capability_limit/business_exclusion/campaign_restriction/preference正确归类，作用域/有效期/来源可查；本次限制不写成长期能力缺陷，偏好不自动否词 |
| QA-08 | 全量语义 | 已完成数量等于应处理或明确失败范围；失败事实不丢弃；重复语义复用有版本；抽样不冒充全量 |
| QA-09 | 意图信息 | 每条保留决定任务、对象、方式与修饰；不抹去离线包、登录、购买对象等；高频模板检查异质样本；无依据不补受众身份、预算、地域和能力 |
| QA-10 | 同义、歧义、品牌 | 同义不制造语义漂移；任务已知不归歧义；未知不默认低；品牌与采购/登录等任务均保留；置信度不由点击量替代 |
| QA-11 | 边界及政策 | 有效经营排除不因转化被覆盖；技术能力与经营选择分开；投放范围外与偏好单列；用户/供应商地域不误当目标对象地域 |
| QA-12 | 诊断及指标 | D1～D5互斥、按周可复算；D1/D2不由否词决定；位置错或本次限制不冒充D1/D2；各质量指标条件/分母一致且不混加 |
| QA-13 | 设置与作用域 | 当前设置有日期/来源；自动定向金额有明确细分来源；整个真实作用域支撑动作，含转化与探索流量；未确认平台规则不假装已确认 |
| QA-14 | 否词集合 | 来源集合与覆盖集合独立；覆盖作用域全部可见关系；资产/上层否词/新增/相关反例检查清楚；集合求并集；匹配模拟限制可见 |
| QA-15 | 否词回写 | 每个可执行否定引用07可执行ID且在覆盖内；所有覆盖关系处置一致；同组同查询不同时保留并组级否定；无历史指令残留 |
| QA-16 | 新增与路由 | 来源、标准化差异、能力/范围、查重/否词可追溯；原查询转化不冒充新词验证；跨结构依赖顺序正确，不能两端同时排除 |
| QA-17 | 动作唯一 | 一ID一原子动作；协调动作有依赖、互斥目标已解决；05～09、04及正文引用同一真值；P1不掩盖待核验 |
| QA-18 | 文本与本期 | 金额/占比/状态/目标值/优先级同步；撤销后无旧指令；上期动作不自动继承；当前范围不由历史归属直接推定 |
| QA-19 | 解释边界 | 无日志不归因于上次优化；无后端不声称有效线索；无匹配收入不算ROAS；没有样本/目标不虚构阈值或行业标准 |
| QA-20 | 交付与可读性 | 实际文件存在可打开，9表齐全，空表原因明确；字段/数值类型/筛选/冻结有效；关键长文本可读；结构/视觉验证分别报告 |
| QA-21 | 可复现与隔离 | 使用的产品/规则/数据版本、来源集合及动作依据随结果可查；不同使用者、产品和本次限制不串用；报告不把业务资料写回通用Skill |

金额显示精度可按0.01检查，但计算保留来源精度；比例应使用重算结果。容差用于合理精度误差，不容忍漏行/重复。ID、分类、规则状态和动作冲突精确比较。

缺少某粒度数据时，对应数值/关系检查“不适用（未提供对应明细）”或“待核验（缺必要资料）”，其支持的其他分析继续；空表不能假称完成全量搜索词核验。

## 2. 重点语义复核

至少覆盖高消费关系、全部可执行否词与新增、业务/能力硬排除、本次范围限制、品牌/实体/地域、能力未知、低置信度、同义表达和高频模板中的不同需求。记录复核范围、实测数量、修正数量与未解决项；没有独立人工标注不声称某个准确率。

以下案例验证通用约束，不提供任何默认产品边界。产品适配按本次业务资料判断。

| 输入/条件 | 应保留的判断 | 禁止的处理 |
|---|---|---|
| 图片爬虫→图片爬取 | 同义图片获取；对象/方式可能未知 | 因换词判漂移 |
| 动态网页抓取→动态网页爬取 | 主任务已知；关键动态渲染能力可待确认 | 将能力未知改成任务歧义 |
| web scraper离线包github | 软件包/资源获取；实体可核验 | 压成获取数据并推断托管API采购 |
| 平台采集工具→数据采集数显机 | 平台任务与设备任务不同 | 因共同“采集”高匹配 |
| 酒店价格数据采集 | 价格是数据对象/字段 | 当服务询价 |
| 数据采集可以赚钱吗 | 收益/变现咨询；具体路径不明 | 直接认采购或确定众包求职 |
| 某省数据交易所官网 | 指定机构导航，目标数据地域未知 | 高采购或依机构名判数据地域 |
| 搜索数据采买 | 采购信号明确，数据类型可能未知 | 全部压成泛查询 |
| 视频字幕提取 | 需要字幕，现成字幕或转写未必明确 | 自动推企业付费、个人无价值或支持ASR |
| google maps api/谷歌地图api | 同义接口需求，适配与位置独立 | 不解释策略差异却说目的不同 |
| 南美客户寄往欧洲的货件 | 客户所在地是南美，服务目的地是欧洲 | 仅见“南美”就否定 |
| 品牌+价格 / 品牌+登录 | 品牌相同，评估与登录不同 | 统一成品牌导航并统一动作 |
| 官网说支持A，用户说暂时不接A | 能力声明与经营限制并存 | 把不接写成技术不支持 |
| 官网没提A，用户也没说明 | 关键能力未知，继续完成不依赖它的分析 | 缺宣传即判不支持，或整个任务停下 |
| 用户“优先企业，个人不太想要” | 偏好，不能凭查询短就断言个人 | 自动批量否定所有工具/免费需求 |
| 产品支持标准和加急配送，当前计划只推标准配送 | 本次范围外，D类仍按产品判断 | 记为永久业务排除或全账户否定 |
| 同组两个词触发相同查询 | 组级否词影响两条关系 | 只回写来源行，另一条还保留 |
| 同组A零转化，B有转化 | 整组设置动作汇总A+B | 用A证明全组无转化 |
| 可服务需求进错组 | 业务相关，评估正确承接及局部路由 | 计D2并全账户否定 |
| 同关键词ID上周A组本周B组 | 历史归属分开，03对象汇总，动作核当前 | 把历史消费归B或以A证明当前作用域 |
| 上周候选，本期无动作ID | 可保留历史诊断，本期无执行命令 | 不否定状态还写执行否定 |
| D1/D2候选因资产冲突未执行 | 诊断不变，动作待核验 | 从明确问题消费删除 |
| 有消费、0目标转化 | CPA不可算，消费如实 | CPA=0 |
| 一个点击多次目标事件 | 保留事件计数，解释可能CVR>100% | 截成100%或叫独立客户数 |
| 同条费用按两个转化事件展开 | 费用底层只算一次，各事件独立 | 费用翻倍或不同事件相加成线索 |
| 只有计划汇总 | 完成计划事实；搜索词页缺失说明 | 编造查询/否词以填满9表 |
| 无收入，只有平台转化数 | 仅对应事件指标，ROAS不可算 | 转化数当订单并估收入 |

## 3. 失败处理与交付声明

可修复的数值、键、引用、状态或文字问题先修复，再复查受影响范围。资料/设置缺失标待核验，保留成立的诊断。未解决的作用范围冲突、必要设置缺失、关键能力未知不能标对应变更可执行。

可以交付有定位的分析草稿，但清楚列未通过部分及使用限制，不声称全部可直接执行。检查状态不是阻止全部分析的开关，也不能把“文件可打开”当所有逻辑已验证。若仅具备结构检查能力，直说未完成视觉检查。

报告交付的是建议，不是账户执行结果；除非用户另行明确授权及工具实际完成，不进行账户变更、邮件发送或外部发布。保存实际产品资料、规则版本、数据摘要、动作台账和检查结果，供下次同产品复用和差异核验。
